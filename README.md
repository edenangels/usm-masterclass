# Ultimate Speaker Masterclass

A learning app for three pathways — **Speaker Masterclass**, **Pitching Success** and **Facilitation Success** — with lessons, quizzes, Arena scenarios, spaced-repetition cue cards, a rehearsal room, blueprints and an atlas of every model.

**Open the app:** https://edenangels.github.io/usm-masterclass/

Progress is saved in your browser. This repository holds the built site only.

Content is an original digest of the models taught in *The Ultimate Speaker Masterclass* (The Mindset Institute).
